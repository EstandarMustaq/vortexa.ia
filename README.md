# Vortexa IA

Vortexa IA é uma aplicação de chat interativo que utiliza inteligência artificial para responder perguntas dos utilizadores de forma clara, objetiva e descontraída. Desenvolvida com tecnologias modernas, mantém-se fiel aos princípios de software livre com copyleft forte, garantindo que todas as versões derivadas permaneçam abertas.

## Tecnologias Principais

- **Frontend**: React.js + Next.js  
- **Backend**: Node.js + Next.js API Routes  
- **IA**: Integração com Groq AI  

## Funcionalidades

- Conversas em tempo real com processamento de linguagem natural.  
- Histórico de interações salvo no navegador e no banco de dados.  
- Modo claro/escuro com alternância dinâmica.  
- Indicador de digitação e feedback visual ao usuário.  
- Compartilhamento de histórico e personalização de temas.  

## Filosofia e Visão

- **Código Aberto com Copyleft Forte**  
  A Vortexa IA foi projetada para ser plenamente aberta e colaborativa.  
- **Experiência do Utilizador**  
  Priorizamos uma interface leve, intuitiva e amigável, com toques de simpatia para tornar as conversas mais humanas.  
- **Transparência Técnica**  
  Embora seja open source, expomos apenas informações essenciais, evitando expor detalhes sensíveis de infraestrutura.
